# Week 2 Day 1 Assignment — Style Your Navigation Bar

## What to do
Using the style.css file, style the navigation bar so it looks 
clean and consistent across all pages.

## Requirements
Your nav bar must have:
- [ ] A background colour (not white)
- [ ] Links with NO underline
- [ ] Links that change colour or style when you hover over them
- [ ] Consistent look across ALL pages (index, about, contact)

## Hints
- All your nav styling goes inside style.css
- You do NOT need to touch the HTML for this assignment
- Use the comments in style.css as your guide
- If you get stuck — Google "CSS navigation bar styling" 
  and see what comes up
